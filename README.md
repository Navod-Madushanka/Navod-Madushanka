### 1. Cloud-Offline Hybrid POS System for Hardware Shops (Sri Lanka)
* **Type:** Production-level SaaS / Hybrid Desktop-Cloud System
* **Tech Stack:** Java, Spring Boot, React, PostgreSQL, Local SQLite/Redis sync layer.
* **Key Features:**
  * **Offline-First Architecture:** Designed for local hardware shops with intermittent internet connections, ensuring uninterrupted POS operations and background syncing.
  * **Sri Lankan Slang Recognition:** NLP-assisted item lookup matching local colloquial terms (e.g., local names for nails, pipes, and fittings) to inventory items.
  * **Hardware Mapping:** Store layout coordinate mapping helping shop owners and staff instantly locate items without manually searching the entire store.
  * **Product Kits:** Bundle management for construction packages (e.g., plumbing kits containing pipes, elbows, and solvent cement).

### 2. Kidney Transplant Compatibility & Risk Assessment System
* **Context:** Developed during my Software Engineering Internship at the Faculty of Engineering, University of Peradeniya.
* **Tech Stack:** FastAPI (Python), PostgreSQL, Redis, Docker Compose, Caddy, Ollama (on-premise vision model), PyJWT.
* **Key Features:**
  * Built a 7-step clinical pipeline handling ABO blood group, HLA mismatch, donor-specific antibodies (MFI), crossmatch, cPRA, and LKDPI risk grading.
  * Engineered an on-premise AI document extraction pipeline using a local vision model to parse HLA typing and 100+ row antibody charts from photos with mandatory doctor verification.
  * Designed a paired kidney exchange module resolving two-way/three-way swaps and altruistic chains via integer programming.
